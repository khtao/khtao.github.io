填写 GitHub Token（可选）

匿名访问 GitHub API 限额是 60 次/小时（同一网络出口共用，公司/校园网很容易打满）。 填入任意有效 Token 后提升到 5000 次/小时，基本不会再看到连接失败。

  1. GitHub 右上角头像 → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. 权限全部留空即可（公开仓库读内容不需要任何 scope）
  4. 生成后复制粘贴到下面，点保存
只保存在本机浏览器，不会发送到任何第三方服务器。
