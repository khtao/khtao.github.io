## 写在前面

这是你把文章上传到 `blog/` 目录后，站点自动抓取渲染出来的样子。**不需要 git 命令**，不需要本地构建，也不需要在本地装任何工具。

> 写作是思考的显影液 —— 只有落笔，模糊的想法才会显形。

## 你可以这样写

支持标准 Markdown 语法：

- **加粗**、*斜体*、~~删除线~~、`行内代码`
- [链接](https://github.com/khtao/khtao.github.io)
- 有序与无序列表

### 代码块

```python
def hello(name: str) -> str:
    """一句问候，开启一段记录。"""
    return f"你好，{name}"

print(hello("世界"))
```

```js
// 前端也一样高亮
const posts = await fetchBlogList()
console.log(posts.length)
```

### 表格

| 能力 | 说明 |
| --- | --- |
| 自动目录 | 读取 `blog/` 目录自动生成 |
| 标签筛选 | 由 frontmatter 的 `tags` 生成 |
| 全文搜索 | 标题 + 正文即时检索 |

### 图片

图片可以直接写相对路径，**以 `blog/` 为根目录**：

![封面图](images/cover.svg)

`![封面图](images/cover.svg)` 会被自动解析成
`https://raw.githubusercontent.com/khtao/khtao.github.io/main/blog/images/cover.svg`，
主源取不到时自动回退到镜像与 jsDelivr。

## 下一步

把你的 `.md` 或 `.html` 文件丢进仓库的 `blog/` 文件夹，刷新页面即可。文章开头加一段 `---` 包裹的 frontmatter，就能自定义标题、日期、标签和摘要。
