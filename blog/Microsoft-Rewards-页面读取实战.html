02 / 积分卡结构：标签 → 相邻数值

不猜字段、不用任务合计倒推，只认页面上那张积分卡。

图 2　把 \" 还原成引号后，两种形态用同一套配对规则
  • 标签表：可用积分 / Available、今日积分 / Points earned today、可领取 / Claimable → 三个键。
  • 取标签后面 1500 字符内的第一个数，允许千分位；两页各解一次，谁有值用谁。
  • 都取不到才退回 balance 之类字段；再不行显示 —，绝不写假的 0。
为什么不用任务合计去算今日积分？ 任务里有一周才做一次的项目，今日积分还可能含额外奖励分。实测任务 110 分、今日积分 100 分，两者本来就不必相等。

06 / 限制与条款

  • 只读，不操作：这里只解释怎么读页面上已经显示的信息，不包含自动搜索、模拟点击或完成任务的实现。
  • 积分合计 ≠ 今日积分：周任务、额外奖励分都会让两者不同，别互相当校验。
  • class 名会改版：text-labelControl、bg-statusSuccessRewardsBg 是样式类，站点改版就可能失效；失败时宁可显示「—」，不要猜数字。
  • 未登录会跳到公开 About 页：识别到就直接提示登录，别把公开页当积分面板解析。
条款提醒　请自行阅读并遵守 Microsoft Rewards 的服务条款：奖励搜索通常要求本人出于真实目的手动完成。任何自动化搜索、批量请求或模拟点击都可能不符合条款，并可能导致积分作废或账户受限。本文与示例代码不含此类功能，也不提供相关实现指导；使用前请以官方最新条款为准。
