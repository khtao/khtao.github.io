直接写 HTML 也可以

把文件保存成 .html 上传，站点会原样嵌入正文区域。你写的 <style> 会被加作用域后原样保留——上面这张卡片的虚线边框、渐变背景、紫色标题，全部来自本文自己的样式表，不受站点主题干扰。

文章之间互链

相对路径指向另一篇文章时，会自动转成站内跳转：← 读《你好，世界》（无需刷新页面）。

其他说明

  • 上传完整 HTML 文档也可以，站点会自动取 <body> 里的内容
  • 外链 CSS（<link rel="stylesheet">）的相对路径同样会被解析
  • 文章内脚本默认不执行，需要时在元信息里加 scripts: true
