直接写 HTML 也可以

把文件保存成 .html 上传，站点会原样嵌入正文区域，样式与 Markdown 文章完全一致。

文件的第一行用 <!-- title: ... | date: ... | tags: ... | summary: ... --> 注释声明元信息；不写也能发布，标题会退化为文件名。

好用的排版元素

  • 加粗、强调、代码
  • 表格、图片、pre 代码块都能正常渲染
<!-- 纯 HTML 片段，不需要 <html> 或 <body> 标签 -->
<p>Hello, GitHub Pages!</p>
格式扩展名
Markdown.md
HTML.html

如果你熟悉前端，这种方式能做出排版更自由的文章。
